# Security Policy

## Reporting Security Vulnerabilities

If you believe you have found a security vulnerability, please report it by:

- **Creating a private security advisory** through GitHub's security tab, or
- **Opening an issue** describing the vulnerability, or
- **Submitting a pull request** with a fix

Please avoid disclosing the vulnerability publicly until it has been addressed.

Thank you for helping us keep AuthMutator secure.
